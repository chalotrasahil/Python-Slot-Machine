# 🎰 Python Slot Machine

A fun and beginner-friendly command-line **Slot Machine Game** written in Python!  
Now with some **extra features** added by me:

## 🚀 Features
- 3x3 Slot Machine with multiple symbols
- Betting system with adjustable lines and bet amount
- Balance system (deposit, play, withdraw)
- **Balance auto-save/load** (your balance continues even after restarting the game)
- **Jackpot Bonus** if you hit all winning lines 🎉
- Beginner-friendly code to learn about loops, functions, input validation, randomness

## 🕹️ How to Play
1. Run the program:
   ```bash
   python slot_machine.py
