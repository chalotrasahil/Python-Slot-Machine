# 🎰 Python Slot Machine

A fun and beginner-friendly command-line **Slot Machine** game written in Python!  
Great for learning about loops, functions, input validation, randomness, and more.

---

## 🚀 How to Play

1. Deposit some money to start.
2. Choose how many lines (1 to 3) you want to bet on.
3. Choose your bet amount per line.
4. Spin the slot machine and try your luck!
5. Winnings depend on symbol value and matched lines.

---

## 🧠 Features

- Bet system with balance tracking
- Randomized 3x3 slot grid
- Symbol probabilities and payout values
- Win detection by matching rows
- Clean, modular code using functions

---

## 🛠️ Requirements

- Python 3.x  
- No external libraries needed (`random` is built-in)
